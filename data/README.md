# Dataset

`housing.csv` is the California housing tabular dataset used for this project. It contains demographic, housing, geographic, and ocean-proximity features with `median_house_value` as the regression target.

The repository keeps the dataset under `data/` so the training workflow is reproducible. If you replace it with another dataset, update the `--data` and `--target` arguments rather than changing the preprocessing code.

Before redistributing the repository, verify the source dataset's licensing and redistribution terms.
